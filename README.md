# Homebrew Tap

Custom Homebrew tap for 0xtlt projects.

## Usage

```bash
brew tap 0xtlt/tap
brew install 0xtlt/tap/md2pdf
brew install vitrail
brew install foldbar
brew install mactmux
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `md2pdf` | Fast, standalone Markdown to PDF converter (Rust; install as `0xtlt/tap/md2pdf`) |

## Available Casks

| Cask | Description |
|------|-------------|
| `foldbar` | Tiny macOS menu bar utility to fold away menu bar icons |
| `mactmux` | Menu bar utility for tmux sessions |
| `vitrail` | Lightweight macOS window layout manager |
